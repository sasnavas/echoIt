# EcoIT 🌍💻
**Smart Carbon Dashboard for SMEs**

## 📖 About the Project
EcoIT is a simple web app for small businesses (SMEs). It acts as a smart carbon calculator. It helps owners see the carbon footprint of their IT devices. 

Our app helps businesses make smart choices. It helps them save energy, save money, and stop "Greenwashing" by using real data.

## ✨ Main Features

* **Real-Time Tracking:** Enter your hardware data, like servers and active hours. The dashboard updates your carbon metrics instantly.
* **Smart AI Tips:** The AI looks at your data. It gives you simple tips to reduce energy waste right away.
* **Clear Reports:** Track your progress over time. This proves your company is truly green.
* **GDPR Ready:** We respect user privacy. You can delete all your data with one click in the Settings menu.
* **Accurate Math:** We use official SEAI formulas. This makes our calculations real and trusted.

## 🛠️ Built With

We built this project to be fast and easy to use. We used standard web tools:
* **Structure:** HTML5
* **Logic:** JavaScript (ES6+)
* **Design:** Tailwind CSS
